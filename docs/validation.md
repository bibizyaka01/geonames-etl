## Дата исходного снимка — 17.11.2026

Добавлены source_last_modified и snapshot_date. Граница дельты определяется
днём исходного архива в Europe/Berlin вместо loaded_at. Старые строки без
метаданных требуют повторной initial; дата не восстанавливается предположением.
При отсутствующем или некорректном Last-Modified загрузка отказывается работать.

Пройдены 16 тестов, включая интеграционные тесты с откатом: старый снимок,
загруженный позже, сохраняет исходную дату; дельта использует дату снимка,
а не loaded_at; неизвестная дата отвергается. Импорт всех трёх DAG успешен.

Реальный запуск `manual__snapshot_date_20261117_232617` завершился успешно:
34 247 строк, source_last_modified = `2026-11-17 02:51:17+00`,
snapshot_date = `2026-11-17`. Следующая ожидаемая публикация дельты — 18 ноября.
Last-Modified не является гарантированной транзакционной границей источника;
такая гарантия GeoNames в используемом описании выгрузок не предоставлена.
